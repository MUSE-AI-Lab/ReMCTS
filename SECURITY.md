# Security Policy

## Generated Code Execution

ReMCTS executes code generated by language models. The included executors use
timeouts and basic safety checks, but they are not hardened sandboxes. Do not
run untrusted generations directly on a workstation or server containing API
keys, private data, network credentials, or valuable writable files. Use an
isolated container or virtual machine with least-privilege filesystem and
network policies.

## Reporting a Vulnerability

Report security issues privately to `yifanyuan@szu.edu.cn`. Include the affected
version, reproduction steps, impact, and any suggested mitigation. Please do not
include working credentials or private benchmark data in the report.
